# Concept

A game idea on its way to a game project. Made by `new-concept.sh`; the stages are in `CLAUDE.md` and in the
workspace's `docs/game-lifecycle.md`.

| File | Stage |
|---|---|
| `design/game-brief.md` | 1. Brief (written by `/prototype`) |
| `design/production-gdd.md` | 2. GDD draft, 4. GDD v1.0 |
| `prototypes/<slug>/` | 3. HTML playtest (built by `/prototype`; open `index.html`) |
| `design/playtest-record.md` | 3. Play sessions and the verdict |
| `design/name-lock.md` | 5. Final name |
| `references/` | Optional images and sounds that shape the look (`references/notes.md`) |
