Use it as a review checklist for screens, HUD, touch targets, text contrast and motion (`/game-ui-design`).
It does not draw art: a game's look comes from its `design/art/ui-prompt-profile.md`, `Tools/ui-kit-template.mjs`
(Pixelorama MCP) and `Assets/Integration/UIPopupStandard.md`, which win on conflict.
The skill is controller-first; web and mobile games are mouse and touch first.
